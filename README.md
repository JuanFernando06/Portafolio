# PZukko · portfolio (Astro)

    npm install
    npm run dev      # desarrollo
    npm run build    # genera dist/

Copia tu carpeta `assets` original dentro de `public/assets/`
(`nutrizukko/`, `pzukko-player/`, `pzukkotip/`, `punto-hogar-luci/` y `cv.pdf`).

- `src/scripts/main.ts`: el brote (canvas), cámara ligada al scroll, intro, fondo, galerías, lightbox y filtros
- `src/data/projects.ts`: datos de los proyectos
